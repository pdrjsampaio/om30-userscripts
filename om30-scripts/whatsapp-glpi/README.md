# OM30 - WhatsApp → GLPI

O arquivo oficial é `/OM30-WhatsApp-GLPI.user.js`.

Ele contém o código completo do sistema e usa a atualização nativa do Tampermonkey por `@updateURL` e `@downloadURL`.

Para publicar uma nova versão, altere o código completo, aumente `@version` e substitua o mesmo arquivo na raiz do repositório.
